FROM SHADER TO GO IMAGE

A texture takes the scenic route.

Both passes run on the GPU in a single frame, with no pixel readback between them. Afterward, ntgpuimage reads back the final frame and the intermediate texture as Go images. Go encodes the PNGs you see above—and the one you download.

Try a small texture and more tiles to see what resolution does to the rings. The final frame stays at 512 × 512.
